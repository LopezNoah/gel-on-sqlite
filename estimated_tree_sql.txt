SCHEMA -> TABLE MAPPING (from src/schema/migrations.ts naming rules)
--------------------------------------------------------------------------------
Tree:
  table  default__tree (
    "id"        TEXT PRIMARY KEY,
    "val"       TEXT,
    "parent_id" TEXT            -- single link `parent` (nullable)
  )
  computed `children` := .<parent[IS Tree]
      -> children of X = rows whose parent_id = X.id

Eert:
  table  default__eert (
    "id"  TEXT PRIMARY KEY,
    "val" TEXT
  )
  multi link `children`
    -> link table default__eert__children ("source" TEXT, "target" TEXT)
       (source = parent node id, target = child node id)
  computed `parent` := (SELECT .<children[IS Eert] LIMIT 1)
      -> parent of X = source where target = X.id   (LIMIT 1)

Conventions used below:
  - Scalar results are returned as a single "value" column.
  - Shaped/object results are returned as a json_object in a "value" column,
    nested multi links via json_group_array(... ORDER BY ...).
  - Empty link arrays render as json('[]').
  - EdgeQL path projections dedup by object identity per hop -> DISTINCT.

--------------------------------------------------------------------------------
UPDATE default__tree
SET "val" = default__tree."val" || '_' || 'c' || COALESCE(
  (SELECT '_' || group_concat(s."val", '_')
   FROM (SELECT c."val" AS "val"
         FROM default__tree c
         WHERE c."parent_id" = default__tree."id"
         ORDER BY c."val") s),
  ''
);
